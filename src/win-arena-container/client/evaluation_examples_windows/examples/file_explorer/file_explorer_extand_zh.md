新增测试用例主要考虑了以下方面：

1. 文件恢复功能：测试文件删除和从回收站恢复的能力，确保文件完整性
2. 文件压缩功能：验证系统内置压缩工具的功能，包括密码保护和压缩选项
3. 文件共享权限：测试文件和文件夹的访问权限设置，确保安全性
4. 文件可见性控制：验证隐藏文件属性的设置和效果，包括系统文件显示选项
5. 文件组织管理：测试文件移动和位置验证功能，保持文件属性完整性

| 测试目的 | 使用说明 | 测试方法 | 评估方式 |
|---------|----------|----------|----------|
| 测试文件删除和恢复 | 从桌面删除指定文件并从回收站还原到原始位置。文件应保持原始名称和内容不变。 | 1. 在桌面创建测试文件"example.txt"<br>2. 右键点击文件选择"删除"<br>3. 打开回收站<br>4. 右键点击已删除文件选择"还原"<br>5. 验证文件返回桌面 | func: exact_match<br>type: is_file_desktop<br>预期结果: 文件成功恢复 |
| 测试文件压缩 | 创建带密码保护的多文件压缩包，使用特定压缩设置。压缩包应创建在指定位置并使用定义的名称。 | 1. 在源文件夹创建测试文件<br>2. 选择所有目标文件<br>3. 右键选择"压缩到ZIP文件"<br>4. 设置压缩选项和密码<br>5. 验证压缩包内容 | func: compare_zip_files<br>预期结果: 压缩文件内容符合预期 |
| 测试文件共享权限 | 为特定用户账户配置文件夹的只读访问权限，确保其他用户无法修改内容但保持读取权限。 | 1. 创建测试文件夹"Shared_Folder"<br>2. 右键选择"属性"<br>3. 进入共享选项卡<br>4. 添加用户并设置"读取"权限<br>5. 应用并验证权限 | func: exact_match<br>type: is_directory_read_only_for_user<br>预期结果: 权限设置正确 |
